stubs one-time .env links
  1. 01 Paste a .env. It's encrypted in your browser.
  2. 02 The key goes in the link, after the #. Our server never sees it.
  3. 03 The first person to open the link gets the values. Then it's void.

FOR AGENTS AND SCRIPTS

Claude Code, Cursor, and Codex can pull a stub into a project without ever seeing the values. @talix/stubs opens the link, writes .env.local, and prints only the key names.

Install the skill (Claude Code, Codex) 
npx -y -- @talix/stubs@{{STUBS_CLI_VERSION}} skill install
Pull a stub 
npx -y -- @talix/stubs@{{STUBS_CLI_VERSION}} pull <link>
MCP server for Claude Code 
claude mcp add stubs -- npx -y @talix/stubs@{{STUBS_CLI_VERSION}} mcp
Or add to AGENTS.md 
When given a link on stubs.talix.app, run `npx -y -- @talix/stubs@{{STUBS_CLI_VERSION}} pull <link>` (or the `pull_stub` tool). It writes the values into .env.local and prints only the key names. Never cat, read, or print .env* files.

To lock a stub to one machine, the recipient runs npx -y -- @talix/stubs@{{STUBS_CLI_VERSION}} init once and shares the id it prints. Full docs: npmjs.com/package/@talix/stubs.
