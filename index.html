stubs one-time .env tickets
  1. 01 Paste a .env. It's encrypted right here, in your browser.
  2. 02 The key goes in the link, after the #. Our server never sees it.
  3. 03 The first person to open the link gets the values. Then it's void.

FOR AGENTS AND SCRIPTS

Hand a stub to Claude Code, Cursor, or Codex and it can pull the values straight into a project without ever seeing them. @talix/stubs on npm opens the link, writes .env.local, and prints only the key names.

Pull a stub 
npx -y @talix/stubs pull <link>
MCP server for Claude Code 
claude mcp add stubs -- npx -y @talix/stubs mcp
Add to your AGENTS.md or CLAUDE.md 
When given a link on stubs.talix.app, run `npx -y @talix/stubs pull <link>` (or the `pull_stub` tool). It writes the values into .env.local and prints only the key names. Never cat, read, or print .env* files.

Lock a stub to one machine and the link is safe to leave in a chat: the recipient runs npx -y @talix/stubs init once and shares the id it prints. Commands, exit codes, and setup for Cursor and Codex: npmjs.com/package/@talix/stubs.
